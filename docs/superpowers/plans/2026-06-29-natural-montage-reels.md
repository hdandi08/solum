# Natural Montage Reels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reusable `stitch.sh` that hard-cuts 2 to 3 second segments from the product films into a hook-led sensory montage, render the first concept ("the part your shower misses"), and reconcile the posting board generator so the new reel and prior fixes are durable.

**Architecture:** One new bash/ffmpeg script (`scripts/social/stitch.sh`) reads a `segments.tsv` (`clip⇥start⇥duration⇥text`), normalizes each trimmed segment to a canonical 1080×1920/30fps/AAC format (guaranteeing an audio track and overlaying any hook text as a PNG in a safe dead-space band), then concatenates them. Concepts live as committed `.segments.tsv` files under `artefacts/social/batch-03-montage/`. The board is generated by `scripts/social/build-board.py`; we update that generator (not the generated `board.html`) and regenerate.

**Tech Stack:** bash, ffmpeg/ffprobe 8.1.1 (no `drawtext` — text via `scripts/social/textcard.py` PNG overlay), Barlow Condensed SemiBold (already at `scripts/social/fonts/`), existing `scripts/social/config.sh` helpers, Python 3 + PIL.

## Global Constraints

Copied verbatim from `docs/superpowers/specs/2026-06-29-natural-montage-reels-design.md` and CLAUDE.md. Every task implicitly includes these:

- **Canvas/encode:** 9:16 = 1080×1920. H.264 `-preset medium -crf 19`, `format=yuv420p`, `setsar=1`, 30fps, AAC 128k @ 48000, `-movflags +faststart`.
- **No `drawtext`:** all burned text is rendered to a transparent PNG via `scripts/social/textcard.py` and composited with `overlay`. Hook text font = **Barlow Condensed SemiBold** (`$FONT_BARLOW`).
- **Editing grammar:** 4 to 6 segments, ~1.5 to 2.5s each, total 9 to 14s; hard cuts; keep real source audio; NO CTA card; NO lower-third caption track; at most ONE short hook line, only in dead space, never over a face/subject.
- **Copy/brand:** never the word "soap". Wordmark only via `web/public/solum-wordmark-white.png` composite, never re-rendered as text. Palette only (SOLUM Black `#08090B`, Bone `#F0ECE2`; no orange/amber/yellow/green). No em-dashes (—), en-dashes (–), or double hyphens (--) in any copy. ≤5 hashtags per post. Both platforms (IG + TikTok) per post.
- **Source films (env-overridable via `config.sh`):** `$SRC_VIDEOS/SOLUM - <NAME>.mp4`. Committed: scripts + `*.segments.tsv` + `*.captions.txt`. Gitignored: rendered `*.mp4`/`*.jpg` (`.gitignore` already ignores `artefacts/social/**/*.mp4`).

### Task 1: `stitch.sh` montage tool

**Files:**
- Create: `scripts/social/stitch.sh`
- Test: manual ffprobe assertions (media tooling; matches the rest of `scripts/social/`).

**Interfaces:**
- Consumes: `config.sh` (`$SRC_VIDEOS`, `$FONT_BARLOW`, `$W916`, `$SOCIAL_DIR`, `verify_dims`, `verify_dur`); `textcard.py`.
- Produces: CLI `stitch.sh OUT SEGMENTS_TSV`. TSV rows = `clip<TAB>start<TAB>duration<TAB>text` (text optional; trailing columns may be absent). `clip` is used as-is if it is an existing file, else resolved as `$SRC_VIDEOS/<clip>`. Output = 1080×1920 H.264 mp4 of all segments hard-cut in order, real audio preserved (silence synthesized for any segment lacking audio), hook text (if present) overlaid in a dead-space band.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
set -euo pipefail
source "$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/config.sh"
OUT="$1"; SEG="$2"
TEXT_Y="${TEXT_Y:-0.10}"   # overlay band (fraction of height); override per concept if it covers a subject
mkdir -p "$(dirname "$OUT")"
TMP=$(mktemp -d); trap 'rm -rf "$TMP"' EXIT
LIST="$TMP/list.txt"; : > "$LIST"

has_audio(){ [ -n "$(ffprobe -v error -select_streams a -show_entries stream=index -of csv=p=0 "$1")" ]; }
VF="scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1,format=yuv420p"

i=0
while IFS=$'\t' read -r clip start dur text; do
  [ -z "${clip:-}" ] && continue
  case "$clip" in \#*) continue;; esac          # allow # comment rows
  [ -f "$clip" ] || clip="$SRC_VIDEOS/$clip"
  seg="$TMP/seg_$i.mp4"
  IN=(-ss "$start" -i "$clip"); idx=1; fc="[0:v]${VF}[v]"
  if [ -n "${text:-}" ]; then
    png="$TMP/t_$i.png"
    python3 "$SOCIAL_DIR/textcard.py" --text "$text" --out "$png" \
      --font "$FONT_BARLOW" --size 72 --width "$W916" --color "#F0ECE2" --box --boxalpha 150 --shadow >/dev/null
    IN+=(-i "$png"); fc="[0:v]${VF}[bg];[bg][${idx}:v]overlay=0:H*${TEXT_Y}[v]"; idx=$((idx+1))
  fi
  if has_audio "$clip"; then amap="0:a"
  else IN+=(-f lavfi -i "anullsrc=channel_layout=stereo:sample_rate=48000"); amap="${idx}:a"; fi
  ffmpeg -y "${IN[@]}" -t "$dur" -filter_complex "$fc" -map "[v]" -map "$amap" \
    -c:v libx264 -preset medium -crf 19 -c:a aac -b:a 128k -ar 48000 "$seg"
  echo "file '$seg'" >> "$LIST"
  i=$((i+1))
done < "$SEG"

ffmpeg -y -f concat -safe 0 -i "$LIST" \
  -c:v libx264 -preset medium -crf 19 -c:a aac -b:a 128k -movflags +faststart "$OUT"
echo "wrote $OUT ($i segments)"
```
